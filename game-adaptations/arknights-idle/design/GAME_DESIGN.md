# GAME_DESIGN — 罗德岛值守协议

## 1. 体验与循环合同

**玩家身份**：罗德岛博士，通过 PRTS 终端管理一支 12 人轮换编队与一座会不断被炸的移动基地。

**玩家承诺**：不需要理智、不需要手操。选好关卡后，战斗、资源、抽卡与养成交给时间；每次回来都能看到明确的战力增长。

**目标感受**：低压、持续增量、有原作质感的“战术挂机”。抽到 6★、精英化、基建暴击率上涨都应有清晰反馈；维什戴尔炸楼提供不可预测的黑色幽默。

**核心动作**：
1. 选择关卡 → 12 人自动部署 → 循环战斗。
2. 用挂机合成玉寻访 → 新干员/潜能。
3. 用关卡资源升级、精英化、技能专精、模组。
4. 用基建材料块无限升级设施，获得极小的全局战斗加成。
5. 回来看离线报告、收源石、维修设施。

**主要先例**：《明日方舟》的编队/职业/精英化/潜能/抽卡，放置游戏的离线收益与无限升级，塔防的阻挡与远程火力。

**原作改变了什么**：
- 去掉理智，关卡失败仍产生挂机收益。
- 干员技能改为自动触发，SP 自动回复。
- 基建不消耗心情，设施无等级上限，但收益曲线收敛。
- 抽卡资源统一为合成玉；源石通过首通与挂机碎片获得。

## 2. 世界规则与进程

**可见信息**：推荐战力、当前编队战力、预估胜率、关卡挂机速率、抽卡概率、保底计数、设施等级与下一级加成。

**隐藏信息**：具体敌人波次与随机掉落、下一次结构判定的结果、抽卡随机结果。

**资源与持久状态**：合成玉、源石、源石碎片、龙门币、资质凭证、养成材料、基建材料块、干员状态、编队、关卡首通、每日任务、抽卡水位、皮肤。

**进程阶段**：
- 0–2 天：建立 12 人编队，解锁 CE-6/LS-6/AP-5，完成首次精英化。
- 3–14 天：推进主线至 8–12 章，形成 6★ 核心，开始专精与模组。
- 14 天以后：15 章、满潜、基建长线、全皮肤收集。

**结束标记**：15-3 首通是本版本内容终点；之后进入收集与基建长线。

## 3. 决策与关卡节拍

- 编队：近战/远程比例、职业协同、谁吃资源。
- 关卡：当前能稳定通关的最高关，还是更低关的挂机效率。
- 抽卡：标准/限定/联动三池独立保底；是否攒 300 抽自选。
- 基建：优先升暴击率（控制中枢）、暴伤（贸易站）、治疗（训练室）还是生命（宿舍）。
- 维修：设施被炸后立即花龙门币恢复，还是先攒资源。

**因果权**：玩家决定编队、关卡、资源分配；战斗过程自动结算。失败不是硬停，而是收益降级并继续挂机。

## 4. 反馈、失败与重开

- 输入反馈：卡片翻转、技能横幅、伤害数字、暴击金色字、基地护盾掉格、设施红色警报。
- 状态变化：战力、资源、等级、潜能、设施等级、挂机速率即时更新。
- 失败原因：防线被突破、超时；结算面板明确说明，挂机收益仍继续。
- 下次可改：提升等级/精英化/换编队/换更低关卡。
- 初态：8 名初始干员、12 个编队位、100 抽、CE-6 为默认挂机关。

## 6. 语言、文化与交接边界

- 界面语言：简体中文；术语沿用明日方舟（干员、精英化、潜能、合成玉、源石、龙门币、基建）。
- 阅读顺序：顶部资源 → 当前页面主任务 → 详情/次级系统。
- 内容尺度：非商业同人；所有素材标注 PRTS Wiki 与鹰角版权。
- 玩家效果：卡牌收集、战力增长、离线收益、黑色幽默事件。

## 7. 可执行切片合同

**最大设计风险**：挂机收益是否让“打不过也能玩”成立，同时不使前期失去成长压力。

**原型形态**：完整 Web 挂机循环，而非纯文字模拟。

**最小状态**：关卡、12 人编队、干员等级/精英/潜能/技能、合成玉、源石/碎片、基建材料块、设施等级、抽卡水位、每日任务。

**初态 → 输入 → 结果**：
- 初态：100 抽、8 人编队、CE-6 可选。
- 输入：点击开始 → 自动战斗 → 胜利获得首通源石与关卡奖励；失败仍积累挂机收益。
- 抽卡：600 合成玉/抽，10 连必得 5★+。
- 300 抽：任意 6★ 自选。
- 离线：按关卡速率结算，上限 8 小时。

**验证切片**：桌面 1440×1000、移动 390×844；启动、战斗、抽卡、养成、基建升级、皮肤购买、300 自选、存档恢复、离线结算。

## 8. 验证切片

**范围**：单机静态 Web；无账号、无联网对战、无付费。
**非目标**：完整复刻全部主线关卡、剧情、干员数量、原版基建排班、云存档。
**会触发设计修改的观察**：
- 新手 100 抽后仍无法在 10 分钟内形成可感知战力增长。
- 15 章前出现必须重复刷数小时才能跨过的硬墙。
- 挂机收益让前期直接跳过抽卡/养成决策。
- 维什戴尔事件频率高到造成持续负体验。
