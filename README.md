# 罗德岛值守协议 · ARKNIGHTS IDLE

一个以《明日方舟》世界观与 PRTS Wiki 资料为基础的非官方同人放置游戏。

**在线游玩：** https://executor0707.github.io/arknights-idle/

没有理智，没有体力。选关之后，干员会自动部署、战斗、循环。你可以关掉页面，回来收合成玉、源石碎片和基建材料。

## 玩法

- **12 人编队**：近战阻挡、远程输出、医疗维持，同职业 2 人起激活协同。
- **无理智挂机**：失败也会继续循环并累积挂机收益，胜负只影响额外战斗奖励。
- **原作概率抽卡**：6★ 2% / 5★ 8% / 4★ 50% / 3★ 40%，50 抽后软保底，标准、限定、联动三个池子独立水位。
- **100 抽初始资源**：新档 60,000 合成玉。
- **300 抽自选**：每累计 300 抽，可兑换任意 6★（含限定、联动）。
- **五潜能**：重复干员提升潜能，3 潜与 5 潜额外强化。
- **原作养成**：等级、精英化、技能 1–7、专精 M1–M3、模组、信赖。
- **资源关复刻**：CE-6、LS-6、AP-5 芯片关、PR-D 芯片组、剿灭作战。
- **首通源石**：每个关卡首次通关掉落源石。
- **源石挂机**：源石碎片按关卡效率产出，20 碎片合成 1 源石；前期约 5 枚/天，十五章约 29 枚/天。
- **124 套时装**：全部来自 PRTS Wiki 的干员时装半身像，统一 88 源石，可购买并装备。
- **无限基建**：设施等级无上限，每级提供极小的暴击率、暴击伤害、攻击、攻速、治疗或生命加成。
- **维什戴尔**：每 2 分钟进行一次结构判定。她真的会炸掉设施，维修要花龙门币。

## 数值基线

| 项目 | 前期（CE-6 / 0-1） | 后期（15-3） |
|---|---:|---:|
| 挂机合成玉 | 6,000 / 小时（10 抽） | 18,000 / 小时（30 抽） |
| 源石碎片 | 4.2 / 小时（约 5 枚/天） | 24.2 / 小时（约 29 枚/天） |
| 基建材料块 | 1.2 / 小时 | 3.2 / 小时 |
| 推荐战力 | 4,200–4,800 | 66,000 |

- 新档 100 抽，加上首通与挂机资源，前期不会因为抽卡资源断档。
- 基建材料块约能支撑前期每天 10–15 级设施升级，之后成本逐步上升。
- 15-3 的推荐战力接近常规满编 E2 队伍，满潜/模组/基建是长线目标。

## 运行

静态站点，无构建步骤：

```powershell
python -m http.server 8765 --directory build/app
# http://127.0.0.1:8765/
```

部署入口为 `build/app/`，GitHub Pages 使用 `gh-pages` 分支。
