# 罗德岛值守协议 · ARKNIGHTS IDLE

一个以《明日方舟》世界观与 PRTS Wiki 资料为基础的非官方同人放置游戏。

**在线游玩：** https://executor0707.github.io/arknights-idle/v4/（旧根地址会自动跳转到此入口）

没有理智，没有体力。选关之后，干员会自动推进、战斗、循环。你可以关掉页面，回来收合成玉、源石碎片和基建材料。

## Spine 说明

- 干员 Spine 同时存在 3.5.51 与 3.8 两代格式：3.5 用旧版 `pixi-spine`，3.8 用隔离 iframe 运行时，避免全局冲突。
- 当前 453/453 名干员有可用的 PRTS Spine 资源。
- 全部皮肤 Spine 已打包到本地 `assets/spine38/skins/`，不再依赖 PRTS 远程加载。当前保留的 528 套皮肤全部可解析战斗 Spine；其中 8 套吟游者皮肤没有攻击片段，但吟游者本身不攻击，按待机/治疗动画显示即可；阵法术师与解放者的 12 套皮肤及其原皮没有原生 Attack，改用 `Skill_1`（或该皮肤可用的技能循环）作为攻击动作；火龙S黑角已改用本地 3.8 模型；3.5 渲染器的干员换肤时改走 3.8 皮肤帧，不会回退默认模型。已购买皮肤卡有独立大小拉条（50%–200%，默认 100%）和「↺」重置按钮；干员详情中的当前皮肤拉条与「时装」商店拉条读写同一个缩放值，二者联动且不会重复相乘。未购买卡片只显示购买提示；设置页全局角色倍率再与之相乘。干员详情中默认皮肤单独提供「战斗小人大小」拉条；购买皮肤统一在时装商店调整。
