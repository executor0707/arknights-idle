# 罗德岛值守协议 · ARKNIGHTS IDLE

一个以《明日方舟》世界观与 PRTS Wiki 资料为基础的非官方同人放置游戏。

**在线游玩：** https://executor0707.github.io/arknights-idle/

没有理智，没有体力。选关之后，干员会自动推进、战斗、循环。你可以关掉页面，回来收合成玉、源石碎片和基建材料。

## 当前版本

- **469 名干员**：全量从 PRTS Wiki 抓取，含异格、限定、联动、活动赠送、2★ 机械干员。
- **531 套时装**：全量半身像，独立「时装商店」，统一 **18 源石**。
- **307 个主线关卡**：0–17 章，通关后自动进入下一关；失败后留在当前关循环挂资源，直到练度足够。
- **37 张剿灭地图**：全量剿灭。
- **325 层无尽战线**：替代原芯片关；逐层提升难度，最高不超过 5 名 6★满练队伍的战力；每层有随机 Boss，失败留在本层循环。
- **无尽收益**：第 1 层 15 抽/小时，逐层提升到第 325 层的 120 抽/小时。
- **通用芯片**：不再区分职业，也不再有芯片关；芯片/芯片组直接进入挂机产出，前期每天约 480 芯片 + 384 芯片组，足够远超 30 名干员精二。
- **材料简化**：精英化只消耗芯片 + 龙门币；技能/专精只消耗技巧概要 + 龙门币；模组只消耗模组数据块 + 龙门币。主线/剿灭不再掉养成材料，资源筹备新增 CA-5 技巧概要关，加工站改产技巧概要。
- **PC 1.75 倍 UI**：全界面放大重排；干员档案卡保持较小尺寸，避免原图被过度放大；抽卡主视觉缩至原尺寸的 80%。
- **横版战斗**：5 人编队，角色在横条战场中向前推进，遇敌停战、清波继续；Spine 单位有跑动起伏，敌人与角色同一条道路线。近战前排阻挡，远程与医疗后排输出。
- **角色大小**：我方默认 120%，敌方默认 100%；系统设置提供两条 50%–200% 滑动条，可分别缩放我方 Spine 与敌方/Boss。
- **攻击节奏**：按职业基准攻击间隔实现，并压缩到 82% 以适配挂机观感；当前不是逐干员 Wiki 攻速。
- **攻击动画**：攻击动作锁定约 0.8 秒，目标死亡也会播完；下一次攻击再重新索敌，所有角色优先选择当前血量最低的敌人。
- **出战顺序**：队伍按编队槽位 1→5 排列，槽位 1 是最前排。
- **漏怪失败**：普通敌人漏过计 1 个，Boss 漏过计 3 个；累计 3 个直接判负，失败留在当前关循环。
- **Boss 倍率**：Boss 综合战力按 5 人队伍平均战力的 1.75 倍换算到 HP/ATK/DEF。
- **战斗演出**：469 名干员全部使用 PRTS Spine 骨骼小人，攻击/技能/眩晕/退场动画；资源加载失败时才回退立绘。敌方使用 3.8 骨骼；boss 按章节使用碎骨、霜星、浮士德、梅菲斯特、岁相、黑蛇等不同模型。
- **博士等级**：无上限；每天最多升 5 级，每级 +5 源石。
- **随机事件**：内置 5–7 小时检查，15% 触发约 60 条干员事件；收益、罚款、设施损坏都会写入档案，不显示倒计时。
- **暂停/离线**：暂停遮罩带继续按钮；页面未关闭时切标签不算离线，只有重新打开页面才结算离线收益。
- **阿米娅升变**：通关 R8-11 解锁近卫形态，通关 14-23 解锁医疗形态；阿米娅详情显示升变入口，两个形态不再进入卡池。
- **寻访展示窗**：主视觉改为当前卡池 6★ 干员半身像展示窗；规则区可查看本池全部 6★。
- **全干员可抽**：标准、限定、联动三个混合池；限定 26 名、联动 29 名。
- **300 抽自选**：任意 6★，含限定与联动。
- **五潜能、精英化、技能专精、模组、信赖**。
- **无理智挂机**：失败仍继续循环并累积合成玉/源石碎片/基建材料。
- **首通源石**：每个关卡首次通关获得源石。
- **无限基建**：每级提供少量暴击率、暴击伤害、攻击、攻速、治疗或生命加成。
- **维什戴尔**：每 2 分钟进行一次结构判定，炸毁设施，维修消耗龙门币。

## 运行

静态站点，无构建步骤：

```powershell
python -m http.server 8765 --directory build/app
# http://127.0.0.1:8765/
```

部署入口为 `build/app/`，GitHub Pages 使用 `gh-pages` 分支。

## Spine 说明

- 干员 Spine 同时存在 3.5.51 与 3.8 两代格式：3.5 用旧版 `pixi-spine`，3.8 用隔离 iframe 运行时，避免全局冲突。
- 当前 469/469 名干员有可用的 PRTS Spine 资源。
- 皮肤专属 Spine **尚未接入**：战斗小人仍使用干员默认皮肤；换装只影响立绘、档案和技能切入。
- 敌方普通单位（士兵、盾卫、术师、猎狗、暴徒）与 6 类 Boss（碎骨、霜星、浮士德、梅菲斯特、岁相、黑蛇）使用 3.8 骨骼，和干员一起在战斗层渲染。
- Spine 资源按战斗编队懒加载，不会一次加载全部。
