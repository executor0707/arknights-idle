# 罗德岛值守协议 · ARKNIGHTS IDLE

一个以《明日方舟》世界观与 PRTS Wiki 资料为基础的非官方同人放置游戏。

**在线游玩：** https://executor0707.github.io/arknights-idle/

没有理智，没有体力。选关之后，干员会自动推进、战斗、循环。你可以关掉页面，回来收合成玉、源石碎片和基建材料。

## 当前版本

- **469 名干员**：全量从 PRTS Wiki 抓取，含异格、限定、联动、活动赠送、2★ 机械干员。
- **531 套时装**：全量半身像，独立「时装商店」，统一 **18 源石**。
- **307 个主线关卡**：0–17 章，通关后自动进入下一关；失败后留在当前关循环挂资源，直到练度足够。
- **37 张剿灭地图**：全量剿灭。
- **无尽战线（9999 层循环关）**：正常只显示当前一关，初始为「无尽战线-0」，每循环一次编号 +1，最高到「无尽战线-9999」；推荐战力从 16,000 起，每层 +8；每层有随机 Boss。胜利自动进入下一编号；失败时回退到前一层挂机，并同时显示「前一层」和「失败层」，打过失败层后前一层自动消失。
- **无尽收益**：第 1 层 15 抽/小时，每层 +0.1 抽/小时；其他资源也随层数无限增长。
- **通用芯片**：不再区分职业，也不再有芯片关；芯片/芯片组直接进入挂机产出，前期每天约 480 芯片 + 384 芯片组，足够远超 30 名干员精二。
- **材料简化**：精英化只消耗芯片 + 龙门币；技能/专精只消耗技巧概要 + 龙门币；模组只消耗模组数据块 + 龙门币。主线/剿灭不再掉养成材料，资源筹备新增 CA-5 技巧概要关，加工站改产技巧概要。
- **PC 1.75 倍 UI**：全界面放大重排；干员档案卡保持较小尺寸，避免原图被过度放大；抽卡主视觉缩至原尺寸的 80%。
- **横版战斗**：5 人编队，角色在横条战场中向前推进，遇敌停战、清波继续；Spine 单位有跑动起伏，敌人与角色同一条道路线。近战前排阻挡，远程与医疗后排输出。
- **角色大小**：我方默认 120%，敌方默认 100%；系统设置提供两条 50%–200% 滑动条，可分别缩放我方 Spine 与敌方/Boss。手机窄屏额外应用 82% 战场缩放，避免 5 人重叠。
- **自动结算**：自动循环开启时，结算显示 4.2 秒倒计时；手动模式可停留选择「下一关 / 退出作战」，尾关显示「再次作战 / 退出作战」。
- **攻击节奏**：按职业基准攻击间隔实现，并压缩到 82% 以适配挂机观感；当前不是逐干员 Wiki 攻速。
- **攻击范围**：近战（先锋/近卫/重装/特种）自动攻击范围为前后约两个身位（26% 战场距离），不再只打被自己阻挡的敌人；远程范围保持原逻辑。医疗治疗无距离限制，按最低血量比例选择目标。
- **医疗**：医疗干员治疗范围无限，战场内所有存活友军均可被治疗；优先选择当前血量百分比最低的目标；普通治疗按医疗干员自己的攻击间隔触发，不依赖 SP。
- **攻击动画**：攻击动作锁定约 0.8 秒，目标死亡也会播完；下一次攻击再重新索敌，所有角色优先选择当前血量最低的敌人。角色专属 Skill、技能切入和技能横幅已恢复。
- **出战顺序**：队伍按编队槽位 1→5 从左到右排列，槽位 5 在最右侧前排。
- **胜利结算**：非尾关显示「下一关 / 退出作战」，尾关才显示「再次作战 / 退出作战」；自动循环开启时仍会倒计时自动进入下一关。
- **漏怪失败**：普通敌人漏过计 1 个，Boss 漏过计 3 个；累计 3 个直接判负，失败留在当前关循环。
- **Boss 倍率**：Boss 综合战力按 5 人队伍平均战力的 1.75 倍换算到 HP/ATK/DEF。
- **击杀即时入账**：每击杀一个敌人立即结算一部分龙门币（约该关龙门币奖励的 35%，Boss 更高），通关时只补剩余部分，避免重复发奖；失败也保留已到手的击杀收益。
- **战斗演出**：469 名干员全部使用 PRTS Spine 骨骼小人，攻击/技能/眩晕/退场动画；资源加载失败时才回退立绘。敌方使用 3.8 骨骼；boss 按章节使用碎骨、霜星、浮士德、梅菲斯特、岁相、黑蛇等不同模型。
- **博士等级**：无上限；每天最多升 5 级，每级 +5 源石。
- **随机事件**：内置 5–7 小时检查，15% 触发约 60 条干员事件；收益、罚款、设施损坏都会写入独立「事件」日志页，可按时间、干员、收益/损失筛选，不显示倒计时。
- **暂停/离线**：暂停遮罩带继续按钮；页面未关闭时切标签不算离线，只有重新打开页面才结算离线收益。
- **阿米娅升变**：通关 R8-11 解锁近卫形态，通关 14-23 解锁医疗形态；阿米娅详情显示升变入口，两个形态不再进入卡池。
- **寻访展示窗**：主视觉改为当前卡池 6★ 干员半身像展示窗；规则区可查看本池全部 6★。
- **全干员可抽**：标准、限定、联动三个混合池；限定 26 名、联动 29 名。
- **300 抽自选**：任意 6★，含限定与联动。
- **五潜能、精英化、技能专精、模组、信赖**。
- **无理智挂机**：失败仍继续循环并累积合成玉/源石碎片/基建材料。
- **首通源石**：每个关卡首次通关获得源石。
- **存档导出**：导出的 `.json` 是 AES-GCM 加密信封，不再直接暴露龙门币、干员、材料等字段；仍支持导入旧版明文存档。注意这是防手改混淆，不是不可破解的 DRM。
- **无限基建**：每级提供少量暴击率、暴击伤害、攻击、攻速、治疗或生命加成；基建页显示每个设施当前加成与每级数值。暴击率达到 100% 时控制中枢封顶。设施被维什戴尔炸毁时加成归零，维修固定 30,000 龙门币。
- **维什戴尔**：每 2 分钟进行一次结构判定，炸毁设施，维修固定 30,000 龙门币。

## 运行

静态站点，无构建步骤：

```powershell
python -m http.server 8765 --directory build/app
# http://127.0.0.1:8765/
```

部署入口为 `build/app/`，GitHub Pages 使用 `gh-pages` 分支。

## Spine 说明

- 干员 Spine 同时存在 3.5.51 与 3.8 两代格式：3.5 用旧版 `pixi-spine`，3.8 用隔离 iframe 运行时，避免全局冲突。
- 当前 469/469 名干员有可用的 PRTS Spine 资源。
- 皮肤专属 Spine：五套皮肤使用本地资源（阿米娅近卫「触及星辰」、艾丽妮「飞羽」、阿斯卡纶「趋光之暗」、安洁莉娜「质素访客」、阿兰娜「赤土拉力」）；其余皮肤按 PRTS `torappu` 的 `meta.json` 从远程按需加载，已映射 524/531 套，缺失资源回退默认骨骼。恢复原始整体高度缩放；已购买皮肤卡有独立大小拉条（50%–200%，默认 100%）和「↺」重置按钮，未购买卡片只显示购买提示；设置页全局角色倍率再与之相乘。干员详情中默认皮肤单独提供「战斗小人大小」拉条；购买皮肤统一在时装商店调整。
- 敌方普通单位（士兵、盾卫、术师、猎狗、暴徒）与 6 类 Boss（碎骨、霜星、浮士德、梅菲斯特、岁相、黑蛇）使用 3.8 骨骼，和干员一起在战斗层渲染。
- Spine 资源按战斗编队懒加载，不会一次加载全部。
