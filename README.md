# 罗德岛值守协议 · ARKNIGHTS IDLE

一个以《明日方舟》世界观与 PRTS Wiki 资料为基础的非官方同人放置游戏。

**在线游玩：** https://executor0707.github.io/arknights-idle/

没有理智，没有体力。选关之后，干员会自动部署、战斗、循环。你可以关掉页面，回来收合成玉、源石碎片和基建材料。

## 当前版本

- **469 名干员**：全量从 PRTS Wiki 抓取，含异格、限定、联动、活动赠送、2★ 机械干员。
- **531 套时装**：全量半身像，独立「时装商店」，统一 **18 源石**。
- **307 个主线关卡**：0–17 章，按章节切换。
- **37 张剿灭地图**：全量剿灭。
- **PC 1.75 倍 UI**：全界面放大重排；干员档案卡保持较小尺寸，避免原图被过度放大。
- **战斗演出**：463 名有 PRTS Spine 资源的干员使用骨骼小人，攻击/技能/眩晕/退场动画；其余干员使用立绘攻击位移、弹道、受击、暴击与技能立绘切入。敌方 5 类敌人使用 3.8 骨骼与攻击动画。
- **全干员可抽**：标准、限定、联动三个混合池；限定 6 名、联动 29 名。
- **300 抽自选**：任意 6★，含限定与联动。
- **五潜能、精英化、技能专精、模组、信赖**。
- **无理智挂机**：失败仍继续循环并累积合成玉/源石碎片/基建材料。
- **首通源石**：每个关卡首次通关获得源石。
- **无限基建**：每级提供少量暴击率、暴击伤害、攻击、攻速、治疗或生命加成。
- **维什戴尔**：每 2 分钟进行一次结构判定，炸毁设施，维修消耗龙门币。

## 运行

静态站点，无构建步骤：

```powershell
python -m http.server 8765 --directory build/app
# http://127.0.0.1:8765/
```

部署入口为 `build/app/`，GitHub Pages 使用 `gh-pages` 分支。

## Spine 说明

- 干员 Spine 同时存在 3.5.51 与 3.8 两代格式：3.5 用旧版 `pixi-spine`，3.8 用隔离 iframe 运行时，避免全局冲突。
- 当前 463/469 名干员有可用的 PRTS Spine 资源，其余 6 名使用立绘演出降级。
- 敌方 5 类（士兵、盾卫、术师、猎狗、BOSS）已使用 3.8 骨骼，和干员一起在战斗层渲染。
- Spine 资源按战斗编队懒加载，不会一次加载全部。
